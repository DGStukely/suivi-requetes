⚙ Configuration SharePoint
SharePoint Online (Microsoft 365) — Site configuré pour Stukely-Sud.
URL du site : https://munstukelysud.sharepoint.com/sites/Doc_Public
Les agents doivent être connectés à leur compte Microsoft 365 dans le navigateur pour que la synchronisation fonctionne.
💡 Prérequis : Les agents doivent être connectés à Microsoft 365 dans leur navigateur (Outlook, Teams, ou portal.office.com) avant d'ouvrir l'application. L'authentification se fait automatiquement via le cookie de session.

Mode hors-ligne : Si SharePoint est inaccessible, l'application bascule en mode local (localStorage).
